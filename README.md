First Flask

Мой первый backend-проект на Python и Flask.

О проекте

Простой Flask-проект, созданный в процессе изучения backend-разработки.

Проект работает как веб-сервер и обрабатывает HTTP-запросы.

Технологии

- Python
- Flask
- Git
- GitHub

Запуск

1. Создать виртуальное окружение:

python -m venv venv

2. Активировать виртуальное окружение:

source venv/Scripts/activate

3. Установить зависимости:

pip install -r requirements.txt

4. Запустить приложение:

python app.py

После запуска приложение будет доступно локально.
